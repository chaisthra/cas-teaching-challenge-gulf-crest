# Dataset Disclaimer

Everything in this folder, including Gulf Crest Insurance Company, Hurricane Marisol, policyholder names, addresses, and financial figures, is synthetic and fictional, built for this teaching module.

No real company, person, or event is represented. The statistical parameters behind the data (claim frequency and severity ranges, fraud rates, catastrophe thresholds, repair cost inflation, storm characteristics) were calibrated against public industry benchmarks and research sources for realism (see `/local/research/` for citations), but no private, proprietary, or identifiable real-world data went into building any of these datasets.

## Datasets in this folder

1. `01_policies` - the synthetic policy book
2. `02_claims` - claims from Hurricane Marisol and from routine (non-catastrophe) activity
3. `03_weather` - Hurricane Marisol event data
4. `04_economic_indicators` - synthetic macroeconomic time series
5. `05_repair_costs` - claim-level repair cost breakdowns
6. `06_fraud_labels` - fraud classification labels for claims
7. `07_reserve_history` - claim reserve development over time
8. `08_company_financials` - Gulf Crest's summary financial statements
